# Project Context: AI Project Discovery Platform

## 1. Project Overview
We are building an AI-powered platform that helps developers of different experience levels discover project ideas, find existing libraries and open-source repositories, and get a step-by-step development roadmap.

## 2. Problem We Solve
Developers often struggle to:
- Find project ideas appropriate for their skills.
- Identify existing libraries and APIs that solve parts of a problem.
- Avoid reinventing existing solutions.
- Break a project into manageable implementation steps.

## 3. Core Features
1. User selects experience level, programming languages, interests and available time.
2. AI generates personalized project ideas.
3. GitHub search finds relevant repositories and beginner-friendly issues.
4. Package registries help identify existing libraries and tools.
5. The platform explains what to build, reuse and extend.
6. Users receive a step-by-step project roadmap.

## 4. Team Responsibilities
- Person 1: Frontend and UI/UX.
- Person 2: AI recommendations and project roadmaps.
- Person 3: GitHub, repository and library discovery.
- Person 4: Backend integration, testing and deployment.

## 5. Collaboration Rules
- Use the existing project structure; do not replace it without team approval.
- Work only on your assigned module and branch.
- Agree on shared interfaces before implementing integrations.
- Do not edit another person's module without coordination.
- Never commit API keys, passwords or other secrets.
- Use mock data when another module is not ready.
- Test changes before opening a pull request.

## 6. Product Principles
- Recommendations must match the user's experience level.
- Prefer verified links and real repositories over invented results.
- Explain why each library or repository is recommended.
- Distinguish between building, reusing and extending functionality.
- Prioritize a working end-to-end MVP over unnecessary features.
